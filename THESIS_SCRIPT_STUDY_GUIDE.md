# Thesis scripts: recommended study order

Read these as a walkthrough, not a batch of commands to execute: several scripts start training, inference, or overwrite outputs at import time. Focus on the final **Instruct-only** study, not earlier combined Instruct+Think experiments.

First read [CONTROLLED_SFT_DATA_INTERVENTIONS_README.md](/fs/scratch/users/bharatpi/causal_political_content/CONTROLLED_SFT_DATA_INTERVENTIONS_README.md) for the six conditions and [MODEL_FINE_TUNING_AUDIT_README.md](/fs/scratch/users/bharatpi/causal_political_content/MODEL_FINE_TUNING_AUDIT_README.md) for the verified training setup. Then follow this order.

## Read only if these topics are in your thesis

- **General instruction following:** [run_ifeval_recovery.py](/fs/scratch/users/bharatpi/causal_political_content/code/evaluation/run_ifeval_recovery.py), [score_completed_ifeval.py](/fs/scratch/users/bharatpi/causal_political_content/code/evaluation/score_completed_ifeval.py), then [paired_ifeval.py](/fs/scratch/users/bharatpi/causal_political_content/code/evaluation/paired_ifeval.py). Explain strict/loose scoring and paired prompt-level comparisons. Check model coverage; do not assume all six conditions were evaluated.
- **Earlier manifesto benchmarks:** [build_benchmark_v1.py](/fs/scratch/users/bharatpi/causal_political_content/code/build_benchmark_v1.py), [run_benchmark_v1.py](/fs/scratch/users/bharatpi/causal_political_content/code/run_benchmark_v1.py), and [evaluate_benchmark_v2_document_majority.py](/fs/scratch/users/bharatpi/causal_political_content/code/evaluate_benchmark_v2_document_majority.py). These explain method development, not the final DOLCI label inventory.
- **New pretrained-base comparison:** [run_probvaa_pretrained_base.py](/fs/scratch/users/bharatpi/causal_political_content/code/evaluation/run_probvaa_pretrained_base.py). A newly queued adapter-free run; consult its current output status before claiming results.

You should ultimately be able to trace one example through **source conversation → binary gates → slant labels → removal membership → training input**, and one evaluation statement through **prompt → raw response → mapped answer → signed policy contribution → difference from Full**. Classification slant labels do not yet map removed examples to the eight evaluation policies.
